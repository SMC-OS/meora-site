# MeOra public site

Static public site for MeOra / Nuvora Development, ready for Vercel.

## Routes
- /
- /privacy
- /delete-account
- /support
- /terms
- /legal

## Vercel
This project is static HTML/CSS and includes `vercel.json` with clean URLs enabled.

After deployment, add the custom domain `meora.app` in Vercel Project Settings > Domains and follow Vercel's DNS instructions in GoDaddy.

Public contact used throughout: support@meora.app
